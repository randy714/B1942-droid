# B1942-droid 🪖

**B1942-droid** is a standalone application launcher and touch control engine designed to run *Battlefield 1942* on Android devices. Built with a sleek tactical dashboard in a *Dark Espresso & Bronze* military theme, this engine brings the classic PC gaming experience directly to your mobile device.

---

## 🌟 Key Features

* **Dark Tactical UI**: Modern military-themed dashboard with real-time FPS performance monitoring and memory status.
* **Embedded Native Engine**: Integrated runtime execution engine bundled directly inside the APK for seamless launch capabilities.
* **Custom Touch Controls**: Tactile 8-way octagonal D-Pad and a prominent red fire button with customizable opacity and scale.
* **Performance & Graphics Tuning**:
  * Frame Rate Limiter: 30 FPS, 60 FPS, 90 FPS, 120 FPS, or Unlimited.
  * Display Resolution Scaling: 50%, 75%, 100%, up to 125% HD.
  * Memory Pool Allocation: 2 GB to 6 GB RAM pool selection.
  * Rendering Engine: OpenGL ES 3.0 & Vulkan Engine support.
* **Multi-Language Support**: English, Bahasa Indonesia, Español, Русский, Deutsch, and Français.

---

## 📋 System Requirements

* **Operating System**: Android 8.0 (API Level 26) to Android 16 (API Level 36).
* **Device RAM**: Minimum 3 GB (4 GB – 8 GB strongly recommended).
* **Storage**: At least 2.5 GB of free internal storage for PC game assets.

---

## 🎮 Game File Installation Guide

The **B1942-droid** app provides the execution engine and touch controls. The actual game assets (*Maps, Sound, Textures, Mods*) must be provided from a PC installation of *Battlefield 1942*.

### 1. Install the APK
* Download `B1942-droid-Debug.apk` from the **Actions** tab (*Artifacts* section) in this repository.
* Install the APK file on your Android device.

### 2. Transfer PC Game Files
* Copy your **Battlefield 1942** game directory from your PC (the folder containing `BF1942.exe` and the `Mods` folder).
* Transfer the folder to your phone's internal storage (e.g., `Internal Storage/BF1942/`).

### 3. Link Game Folder in App
1. Launch the **B1942-droid** application.
2. Grant **All Files Access** (*Manage External Storage*) permission when prompted.
3. On the main dashboard, tap **MODS / DATA**.
4. Navigate to and open your game folder (`/BF1942/`).
5. Tap **USE THIS GAME FOLDER**.
6. Return to the main menu and press **START BATTLEFIELD 1942** to launch the game!
